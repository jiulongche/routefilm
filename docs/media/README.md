# Demonstration Media

- `routefilm-poster.jpg` is the final national-route poster from the original production.
- `routefilm-five-stops-demo.mp4` is a silent excerpt covering the first five arrivals: Haikou, Xuwen, Zhanjiang, Nanning, and Hechi.
- `routefilm-preview.gif` is an 11.5-second README preview derived from the silent excerpt.
- `routefilm-full-storyboard.jpg` is the 1440×2240 production contact sheet showing the full arrival and landmark treatment.
- `social-preview.png` is the 1280×640 repository sharing card composed from frames in the silent excerpt.

The poster, excerpt, GIF, storyboard, and social preview are derived from the final v15 production. The video-derived media contains no bundled third-party music and retains visible OpenStreetMap attribution.
